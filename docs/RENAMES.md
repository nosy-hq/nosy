# Renames: Turkish → English (English migration, 28 Sep 2026)

Everything in Nosy is English now: files, folders, script names, JSON keys, CLI flags, messages and docs. Use this map to port work written against the old names. The migration was mechanical for names (one canonical English word per Turkish word, applied the same way everywhere), so a key or variable you knew is the same words in English, joined the same way (`duyuruTarih` → `announcementDate`, `aktif_gun_medyan` → `active_day_median`).
